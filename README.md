# Custom Bracelet Platform

A premium, made-to-order custom bracelet e-commerce experience for the Egyptian market — featuring a live 3D Bracelet Studio, a community design gallery, and (in later phases) AI-powered design generation, digital bracelet passports, real-time collaborative design, and AR try-on.

## Documents
- `CLAUDE.md` — standing instructions for the AI pair programmer (read first)
- `docs/PHASE-1-SPEC.md` — full Phase 1 build specification
- `docs/ROADMAP.md` — all phases + git workflow

## Stack
Next.js 15 · TypeScript · Tailwind + shadcn/ui · React Three Fiber · Supabase (Postgres/Auth/Storage) · Drizzle ORM · Zustand · Paymob · Vercel
